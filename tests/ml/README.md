# tests/ml/

Model metric regression tests — placeholder until **Sprint 10** (churn model: `ml/churn/`, ROADMAP.md) and **Sprint 11** (segmentation: `ml/segmentation/`) land. Once non-trivial, this directory asserts a retrained or refactored model doesn't quietly regress below a documented floor for ROC-AUC/F1/PR-AUC/calibration (churn) and produces a sane segment distribution — no `>90%`-in-one-bucket collapse (segmentation), matching each sprint's stated acceptance criteria in [ROADMAP.md](../../ROADMAP.md). `.github/workflows/ml.yml` runs a small-sample smoke-test version of this same gate on every PR touching `ml/`, so the floor asserted there and the floor asserted here should stay in sync — see that workflow's inline documentation for the current floor values and why they're lower than full-volume champion-model numbers.
