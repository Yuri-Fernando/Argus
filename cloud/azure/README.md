# cloud/azure/

This is the platform's **implemented primary cloud** — every resource described in [ARCHITECTURE.md](../../ARCHITECTURE.md) (ADLS Gen2, Data Factory, Event Hubs, Azure Databricks, Key Vault, Entra ID, Azure Monitor, Azure OpenAI) is real, provisioned via Terraform, and actually deployed against a personal-budget sandbox subscription — see [ADR-001](../../docs/decisions/ADR-001-cloud-strategy.md). The Terraform module set that provisions it lives at [`terraform/modules/azure/`](../../terraform/README.md) (owned by the infrastructure workstream); this directory holds no infrastructure code of its own, only this pointer. For the full architecture these resources support, see [ARCHITECTURE.md](../../ARCHITECTURE.md); for how they're provisioned and torn down between demos, see [`docs/deployment.md`](../../docs/deployment.md).
